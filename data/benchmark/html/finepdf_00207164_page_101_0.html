Image size Sets the image size to [C4K] (Custom only), [4K], [FHD] (Full HD), or [HD].
Bit rate Sets the bit rate to [A-I] (All-Intra), [SF] (Super Fine), [F] (Fine), or [N] (Normal). • [A-I] (All-Intra) is not available for use with Clips. • When [4K] or [C4K] is set for the image size, you cannot select the bit rate.
